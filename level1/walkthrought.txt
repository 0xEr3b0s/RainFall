# 4. Redirecting execution to `run()`

```bash
python -c 'print("A"*76 + "\x44\x84\x04\x08")' > /tmp/sc
(cat /tmp/sc; cat) | ./level1
```

The first command generates 76 `A` characters followed by the address of the `run()` function (`0x08048444`). The address is encoded in little-endian byte order, as expected on this 32-bit x86 system.

The 76 characters overwrite the data between the start of the input buffer and the saved return address. The address that follows overwrites that return address, redirecting execution to `run()` when `main()` returns.

The second command pipes the contents of `/tmp/sc` into `level1`. The first `cat` sends the prepared input, while the second `cat` keeps reading from standard input, allowing further input to be sent to the program's input stream if the spawned shell inherits it.
